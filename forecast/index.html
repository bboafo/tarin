Frozen

This forecast can't be changed after the fact

It was written to a file before GSS published any of these months, and the file's SHA-256 fingerprint was recorded. Download it and run shasum -a 256 on it: if the result matches, it is the forecast as made. It will be scored against the first figure GSS publishes for each month, so a later revision can't flatter it.
